# YONEDA — Formalization of the Yoneda Lemma in Isabelle (`Yoneda.thy`) and LaTeX (`yoneda.tex`)

## Overview
`YONEDA` provides both an Isabelle formalization (`Yoneda.thy`, `mylibrary.thy`) and a typeset mathematical exposition (`yoneda.tex`, `yoneda.pdf`, `gdmath.sty`) of the Yoneda Lemma, representable functors, universal properties, and duality in category theory.
